Arka planda olan şey:
print(name) çağrılır.
print, name nesnesine "kendini yazıya çevir" der, yani name.__str__() çağrılır.
str.__str__ zaten yazı olduğu için aynen "merhaba" döndürür.
print bunu ekrana basar.
python
name = "merhaba"
print(name.__str__())   # merhaba

python
print(25)       # int.__str__ çalışır, "25" olur
print(3.5)      # float.__str__ çalışır, "3.5" olur
print(True)     # bool.__str__ çalışır, "True" olur

Python'daki her nesnenin bir __str__'ı vardır. Yerleşik tiplerde (str, int, float...) bu zaten yazılmış geliyor.
Kendi sınıfında yazmazsan object'in varsayılan __str__'ı çalışır ve <__main__.Kedi object at 0x...> gibi anlamsız bir şey basar.
Yani __str__ yazmak, "benim nesnem yazıya çevrilirken böyle görünsün" demektir.
f-string'de de aynı:
python
print(f"{name}")
{name} kısmı yerleştirilirken yine __str__ çağrılır. 

Exception ile bağlantısı:
print(e) yazdığında e bir PlantError nesnesi olduğu için Exception.__str__ çalışıyor.
O da args'taki mesajı döndürüyor. Yani name'in yazıyı olduğu gibi döndürmesiyle aynı mantık,
sadece Exception sınıfı mesajı args'tan alıyor.
Python'da {e} ifadesi, oluşan hatanın (bu durumda ValueError) Python tarafından otomatik olarak üretilen
orijinal hata mesajını tutar. print(f"Invalid parameter: {e}") yazdığınız için, Python'un kendi teknik açıklaması
(invalid literal for int() with base 10: 'd') sizin yazdığınız metnin sonuna eklenir.

class GardenError(Exception):
    def __init__(self, message: str = "Unknown garden error") -> None:
        super().__init__(message)

class TemperatureError(GardenError):
    def __init__(self, message: str = "Unknown temperature error") -> None:
        super().__init__(message)

def input_temperature(temp_str: str) -> int:
    try:
        temp = int(temp_str)
    except ValueError as exc:
        raise TemperatureError(f"'{temp_str}' is not a valid number") from exc
    if temp < 0 or temp > 40:
        raise TemperatureError(f"{temp}°C is out of range for plants (0-40°C)")
    return temp
