“Ortam” = programın çalıştığı terminal oturumu (işletim sistemi).
Config (yapılandırma): Programın davranışını ayarlayan değerler. Örneğin “hangi moddasın?”, “API anahtarın ne?”, “hangi veritabanına bağlanacaksın?”. Bunları kodun içine yazmazsın, dışarıdan verirsin. Böylece kodu değiştirmeden programın davranışını değiştirebilirsin.

By default, load_dotenv() will:

Look for a .env file in the same directory as the Python script (or higher up the directory tree).
Read each key-value pair and add it to os.environ.
Not override existing environment variables (override=False). Pass override=True to override existing variables.
env dosyasındaki satırları ortam değişkeni olarak yükler. True/False sadece “dosya bulundu mu, bir şey yüklendi mi” bilgisidir.

Programın kendi ortam değişkenleri tablosuna. Python çalışırken işletim sistemi ona bir “env” sözlüğü verir, Python bunu os.environ olarak sunar. load_dotenv() .env dosyasındaki satırları bu sözlüğe ekler.

Örnek 1: Tek dosya import etmek

main.py

python
import selam
print(selam.x)

python3 main.py dediğinde adım adım:

Adım 1. Python main.py’yi çalıştırmaya başlar. sys.path[0] = proje/ klasörü olur.

Adım 2. import selam satırına gelir. sys.modules (yüklenmiş modüller listesi) içine bakar. Şu an selam yok.

Adım 3. sys.path içindeki klasörlere sırayla bakar. İlk klasör proje/. Orada selam.py var. Bulundu.

Adım 4. selam.py’yi baştan sona çalıştırır. Ekrana selam.py çalışıyor yazılır. x = 5 satırı çalışır, yani x diye bir değişken oluşur.

Adım 5. Bu dosya çalışırken oluşan her şey (x gibi) bir “modül nesnesi”nin içine konur. Bu nesne sys.modules["selam"] olarak kaydedilir.

Adım 6. main.py içinde selam ismi bu nesneye bağlanır. selam.x yazınca nesnenin içindeki x okunur, yani 5.

Çıktı:

selam.py çalışıyor
5

“Modül nesnesi” dediğim şey, dosyanın içinde tanımlanan isimlerin (değişken, fonksiyon) durduğu bir kutu. Dosya çalışınca kutu dolar, sen de selam. diyerek kutunun içinden alırsın.
