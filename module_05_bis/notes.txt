Git nedir?
Git, dosyalarının geçmişini kaydeden bir sürüm kontrol sistemidir.
Kodunda her önemli değişiklikte bir commit çekersin.
Eski bir sürüme geri dönebilirsin.
Neyin, ne zaman, kim tarafından değiştirildiğini görebilirsin.
Birden fazla kişi aynı projede çakışmadan çalışabilir.
Denemeler için ayrı dallar (branch) açıp ana koda dokunmadan çalışabilirsin.

Repo (repository) nedir?
Projenin klasörü ve o klasörün tüm geçmişidir. Bir klasörde git init dediğinde,
içinde gizli bir .git/ klasörü oluşur. Geçmiş kayıtları orada durur. Bu klasör artık bir repo’dur.
bash
git init              # klasörü repo yap
git add .             # değişiklikleri kayda hazırla
git commit -m "ilk"   # kaydet

.gitignore nedir?
Git’e “şu dosyaları takip etme, kaydetme, GitHub’a gönderme” dediğin metin dosyasıdır.
Proje klasörünün içine .gitignore adıyla koyarsın, her satıra bir kural yazarsın:
.env
.venv/
__pycache__/
*.pyc
data/büyük_dosya.csv
Neden var?
Gizli bilgiler: .env içinde API anahtarları, şifreler olur. repoya giderse herkes görebilir,
çalınabilir.En önemli sebep budur.
Otomatik üretilen dosyalar: __pycache__/, *.pyc gibi dosyalar kodundan zaten yeniden üretilir,
repoyu şişirir.
Sanal ortam: .venv/ yüzlerce MB olabilir ve her bilgisayarda poetry install ile yeniden kurulur,
paylaşmaya gerek yok.
Büyük veya kişisel dosyalar: Büyük veri setleri, loglar, editör ayarları (.vscode/, .idea/).


“Şu anki paket” hangisi?

Kod hangi dosyada yazıyorsa, o dosyanın ait olduğu paket. __init__.py dosyası alchemy/ klasöründe durduğu için,
onun “şu anki paketi” alchemy’dir.
Adım 3: Modül ve paket farkı
Modül = tek bir .py dosyası. (elements.py)
Paket = içinde modüller olan klasör. (alchemy/)

Örnek 1: Tek dosya import etmek
main.py ::

import selam
print(selam.x)

python3 main.py dediğinde adım adım:
Adım 1. Python main.py’yi çalıştırmaya başlar. sys.path[0] = proje/ klasörü olur.
Adım 2. import selam satırına gelir. sys.modules (yüklenmiş modüller listesi) içine bakar. Şu an selam yok.
Adım 3. sys.path içindeki klasörlere sırayla bakar. İlk klasör proje/. Orada selam.py var. Bulundu.
Adım 4. selam.py’yi baştan sona çalıştırır. Ekrana selam.py çalışıyor yazılır. x = 5 satırı çalışır, yani x diye bir değişken oluşur.
Adım 5. Bu dosya çalışırken oluşan her şey (x gibi) bir “modül nesnesi”nin içine konur. Bu nesne sys.modules["selam"] olarak kaydedilir.
Adım 6. main.py içinde selam ismi bu nesneye bağlanır. selam.x yazınca nesnenin içindeki x okunur, yani 5.

output :
selam.py çalışıyor
5

Burada alchemy paketinin kendisinde create_air adında bir isim olması lazım. Ama __init__.py içine import alchemy.elements yazarsan, alchemy isim alanına sadece elements adı eklenir. Yani şu çalışır:
alchemy.elements.create_air()
ama şu çalışmaz:
alchemy.create_air()
from .elements import create_air içindeki nokta “bu paketin kendi içindeki elements” demek (relative import). Noktasız yazarsan:
from elements import create_air

Python elements’i paket içinde değil, sys.path’te arar. Orada da kök dizindeki elements.py var, yani yanlış dosyayı bulur ve create_fire/create_water gelir, create_air bulunamaz.
import alchemy yazdığında Python alchemy klasörünü bulur ve alchemy/__init__.py dosyasını çalıştırır. Klasör de bir modül nesnesi olur, ve __init__.py içinde ne üretilirse o paketin isim alanına yazılır.
