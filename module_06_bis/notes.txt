The all() function returns True if all items in an iterable are true, otherwise it returns False.
If the iterable object is empty, the all() function also returns True.
Note: When used on a dictionary, the all() function checks if all the keys are true, not the values.

• append(): Listenin sonuna tek bir öğe ekler.
Bu öğe bir sayı, bir string veya başka bir liste (iç içe liste / nested list) olabilir.
• extend(): Kendisine verilen yinelenebilir (iterable - liste, demet, string vb.)
bir nesnenin tüm elemanlarını tek tek ana listenin sonuna ekler.
append(x): x’i listeye tek bir eleman olarak ekler.
extend(iterable): iterable’ın içindeki her elemanı tek tek listeye ekler.
python
a = [1, 2]
a.append([3, 4])   # [1, 2, [3, 4]]  -> liste içinde liste
b = [1, 2]
b.extend([3, 4])   # [1, 2, 3, 4]    -> elemanlar tek tek
